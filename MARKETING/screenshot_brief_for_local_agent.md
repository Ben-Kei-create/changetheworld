# TERRA ストア用スクリーンショット撮影指示（ローカルMac用）

## 目的
Mac App Store 提出用に、実際に動作する TERRA の画面を撮影する。
アプリ本体のコード・設定は変更しない（読み取りと実行のみ）。

## 前提
- 作業フォルダ：このリポジトリのルート（`TERRA/` が直下にある場所）
- ブランチ：`claude/pensive-fermat-gte652`（最新を pull しておく）
- macOS 14 以降、Xcode 15 以降

## 1. 起動
次のどちらかでアプリを起動する。動く方でよい。
- `cd TERRA && swift run`
- `open TERRA/Package.swift` で Xcode を開き、My Mac で Run

起動できない・クラッシュする場合は、エラー全文を報告して止める（コードは直さない）。

## 2. 撮影条件
- 表示言語：日本語（`ja`）。初回起動の流れ（言語選択 → オンボーディング → 「君はどこからきた？」）から撮り始める。
- 初回状態に戻したい場合：保存データを消す前に、何を消すかを報告してから実行する。
- 「君はどこからきた？」には、個人情報でないサンプル文（例：「祖母の台所」）を入力する。
- 通知やメニューバーの個人情報、デスクトップの背景が写り込まないようにする。
- アプリのウィンドウを、16:10 になるようにそろえる（コンテンツ領域 1440×900 ポイントが目安）。

## 3. 撮影する画面（5〜6枚。この順で、物語の流れが伝わるように）
1. メインメニュー（地球）
2. 世界地図（キャラクターのピン）
3. キャラクター紹介パネル
4. ストーリーの選択場面（「あなたはどうする？」）
5. リアルワールド・コンテキスト（実データのカード）
6. インパクトレポート

画面に出ていない機能を、写っているように加工しないこと。

## 4. 書き出し仕様（Apple 公式の Mac 仕様）
- 寸法：2880×1800 px（16:10）。2560×1600、1440×900、1280×800 も可だが、2880×1800 を優先する。
- 形式：PNG または JPEG。**アルファ（透過）なし**。
- 影つきのウィンドウ撮影は使わない。使う場合は影なし（`screencapture -o -l <windowID>`）か、領域撮影（`screencapture -x -R x,y,w,h`）にする。
- 16:10 にならない場合は、アプリの背景色と同じ単色の背景に、元の画面を拡大・変形せず中央配置して 16:10 に整える。その場合は、どの画像をそうしたか報告する。

## 5. 保存先
- 提出用：`screenshots/terra/store/01-menu.png` … `06-impact.png`
- Web 用：`screenshots/terra/web/01-menu.jpg` …（幅 480px 前後、JPEG、1枚約 100KB 以下、全体で約 1MB 以内）
- `TERRA/` 配下には何も置かない。コミットはしない（置くだけ）。

## 6. 検証と報告
各ファイルについて、次を確認して表にして報告する。
- 寸法（`sips -g pixelWidth -g pixelHeight`）
- アルファの有無（`sips -g hasAlpha`）→ すべて `no`
- ファイルサイズ

あわせて、撮影中に気づいた不具合（崩れ、文字切れ、音が鳴らない、クラッシュ、日英の混在など）を、画面名つきで列挙する。修正はしない。

## やらないこと
- `TERRA/` 配下の変更、コミット、push、App Store Connect の操作、Archive・アップロード。
