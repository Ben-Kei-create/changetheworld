# TERRA アプリアイコン制作指示（Codex向け）

## 目的
Mac App Store 提出用の TERRA アプリアイコン一式を作成する。
このタスクは「デザイン案と画像ファイルの作成」まで。アプリ本体（`TERRA/` 配下）への適用・コミットは行わない。

## アプリの背景
- TERRA — Stories of Our World：世界の7人の人生を追体験する、静かな物語ゲーム（macOS）。
- 雰囲気：深い宇宙の暗がりに、柔らかく光る地球。ミニマル、静謐、希望。
- 既存のデザイントークン：`TERRA/Sources/TERRA/App/DesignTokens.swift`（配色はここに合わせる）
- 既存の仕様メモ：`TERRA/Sources/TERRA/Resources/AppIcon.md`

## デザイン要件
- モチーフ：発光する地球（シンプルな球体1つ）。背景は深宇宙の暗色。
- キャンバス全体を使う。不要な外枠・余白・角丸の自前描画はしない（macOS が形状を適用する）。
- グラス表現、複雑なグラデーション、細かい文字は使わない。16px でも球体が識別できること。
- 文字（"TERRA" 等）は入れない。
- 既存ブランド（Google Earth、Apple 純正アイコン等）の模倣をしない。
- 全て自作のベクター/ラスタで制作し、第三者素材を使わない（権利確認のため、制作方法を記録する）。

## 成果物
1. 原画：1024×1024 px、PNG、透過なし（不透明）、sRGB。
2. 書き出し（macOS AppIcon の全スロット）：
   - 16, 32, 64, 128, 256, 512, 1024 px の PNG
   - 対応表：16@1x=16 / 16@2x=32 / 32@1x=32 / 32@2x=64 / 128@1x=128 / 128@2x=256 / 256@1x=256 / 256@2x=512 / 512@1x=512 / 512@2x=1024
   - ファイル名：`icon_16x16.png`, `icon_16x16@2x.png`, `icon_32x32.png`, `icon_32x32@2x.png`, `icon_128x128.png`, `icon_128x128@2x.png`, `icon_256x256.png`, `icon_256x256@2x.png`, `icon_512x512.png`, `icon_512x512@2x.png`
3. 上記ファイル名に合わせた `Contents.json`（AppIcon.appiconset 用）。
4. Web 用：`icon.jpg`（64×64 px、約25KB以下）。
5. 制作メモ：使用ツール、色コード、素材の権利について一言。

## 保存先
`design/terra-icon/` 配下（このフォルダ内だけに出力。`TERRA/` 配下には置かない）。

## 検証
- 全ファイルの寸法と形式（PNG・不透明）を確認する。
- 16px / 32px に縮小した見え方を確認し、球体が潰れていないことを報告する。
- `Contents.json` のファイル名と実ファイルが1対1で一致することを確認する。

## やらないこと
- `TERRA/Sources/...` の変更、コミット、PR 作成。
